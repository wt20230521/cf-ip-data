# PrismTun 订阅托管：Cloudflare Worker + KV（方案①）与静态托管（方案②）

## 一、先搞清一件事：两种方案差在哪

| | ① Cloudflare Worker + KV | ② 任意静态托管（贴 txt） |
|---|---|---|
| 本质 | 一个极小的「写入接口 + 读取接口」 | 一个能被 HTTP 直接抓到的 txt 文件 |
| App 内一键更新 | ✅ 有 API，点一下就传 | ❌ 要手动传文件（除非平台也有 API） |
| 上手难度 | 10 分钟，一次性 | 1 分钟，传个文件就完事 |
| 国内速度 | 绑自己的域名后不错（workers.dev 域名本身不稳，见下文） | 看托管商：国内 OSS/COS + CDN 最快 |
| 费用 | 免费额度绰绰有余 | 免费，或国内对象存储几毛/月 |
| 维护 | 零维护，KV 不用管 | 零维护 |
| 隐私 | 读公开、写要 token | 链接=内容，靠路径不可猜来保护 |

一句话：**想让 App 里点一下就更新 → 选①；只是偶尔换一次、懒得折腾后端 → 选②。**

## 二、方案①：Cloudflare Worker + KV（推荐）

### 2.1 部署（面板方式，不用装任何工具）

1. 登录 Cloudflare → 左侧 **Workers 和 Pages** → **创建** → **创建 Worker**，名字随意（如 `prismtun-sub`），先「部署」一次（会生成默认的 Hello World）。
2. **存储和数据 → KV → 创建命名空间**，名字比如 `PrismTunSub`，记住它。
3. 回到 Worker → **设置 → 绑定 → 添加绑定 → KV 命名空间**：
   - 变量名称必须填 **`SUB_KV`**（代码里就是这个名字）
   - KV 命名空间选刚建的那个
4. **设置 → 变量和机密 → 添加**（两个都把类型选成「**机密**」，加密存储，日志和面板都看不到明文）：
   - `UPLOAD_TOKEN` = **上传口令**，可以直接用这串现成的：**`pt-99075130879a`**（想换随便改）
   - `READ_TOKEN` = **读订阅口令**，**可选**。不设 = 拿到链接就能看；设了 = 读取必须带 `?token=xxx`（见 2.6，推荐设一个）
5. Worker → **编辑代码**，把本目录 `worker.js` 的内容整段粘进去（覆盖默认的 Hello World）→ **部署**。
6. 访问 `https://prismtun-sub.xxx.workers.dev`，应该看到一段说明文字，说明跑起来了。

命令行党：`npx wrangler deploy`，配好 `wrangler.toml` 里的 KV id，再用 `npx wrangler secret put UPLOAD_TOKEN` 写口令。

### 2.2 接口

```
取订阅   GET    https://你的域名/ct                      ← 客户端订阅填这个
上传     POST   https://你的域名/api?token=口令&key=ct    body = 订阅内容
列表     GET    https://你的域名/api?token=口令&action=list
删除     DELETE https://你的域名/api?token=口令&key=ct
```

App 里三个网络默认用三个 key：**ct（电信）/ cmcc（移动）/ cu（联通）**，想改在 App 里改。

### 2.3 国内访问：这一段一定看

- `*.workers.dev` 这个默认域名在国内**经常抽风**（时快时慢、偶尔不通），别把它当最终订阅地址。
- 正确做法：Worker → **设置 → 域和路由 → 添加自定义域**，绑到你自己的域名（如 `sub.你的域名.com`）。DNS 托管在 Cloudflare 最省事，一条 CNAME 就行。
- 如果你域名 DNS 不在 CF：CNAME 到 Worker 地址，CF 面板会自动签发证书。
- 还想再稳一点：用「CF 优选 IP」类的 CNAME 服务把自定义域指到延迟低的节点，或套一层国内可直连的反代。**没有自己域名的话，方案①的优势会打折**——这种情况建议直接用方案②里的国内对象存储。

### 2.4 额度

免费版：Worker 每天 10 万次请求，KV 每天 10 万次读、1000 次写、存 1GB。我们一天顶多几十次读写，**免费额度用到天荒地老**。

### 2.5 数据能存多久 / 覆盖规则（常被问）

- **不会过期**：代码里 `SUB_KV.put(key, body)` 没有设置 `expirationTtl`，所以是**永久保存**。Cloudflare 也不会因为「长期没人访问」把数据清掉（不活跃只影响 Worker 冷启动，不影响 KV 内容）。
- **同名覆盖，不堆积**：往同一个 key（`ct`）再传一次，是**直接覆盖**，KV 里始终只有最新那一份，旧的立刻被替换，不会越攒越多。订阅链接也不变，客户端下次拉取就是新内容。
- **换 key 才会留孤儿**：如果你把文件名从 `ct` 改成了别的（或改成随机串），**旧的那个 key 还会在 KV 里躺着**，不会被自动删除。用 `action=list` 看一眼有哪些 key，多余的用 DELETE 接口或面板删掉。
- **生效有 60 秒延迟**：KV 是全球多点的，更新后边缘缓存最长 **60 秒**才完全同步。所以上传完立刻刷新可能还是旧的，等一分钟再看（客户端里点「更新订阅」同理）。
- **删除不可恢复**：DELETE 或面板删除后就没了，删之前确认。
- **容量**：单个 value 上限 25MB（本 Worker 代码里额外限制 1MB），免费账号总共 1GB 存储、每天 10 万读 / 1000 写，够用。

### 2.6 读保护：让订阅链接也保密（可选，推荐）

默认读订阅是**公开**的（客户端要能匿名拉取，这是订阅的常态），代价是**谁拿到链接谁就能用你的节点**。想收紧就设一个 `READ_TOKEN`：

- 设了之后，读取地址变成：`https://sub.你的域名.com/ct?token=你的读口令`
- **上传接口返回的 url 会自动带上这个 token**，App 里「🔗直链」复制出来的就是能直接用的完整地址，不用自己拼
- 客户端那边照粘即可：Clash / v2rayN / 小火箭 / sing-box / NekoBox 都支持带参数的订阅地址
- ⚠️ **读口令别和上传口令设成一样** —— 读口令会出现在订阅链接里（客户端要用），等于半公开；上传口令是最高权限，必须独立

不设也行，那就靠"路径不可猜"来保护（把 key 从 `ct` 改成随机串）。

## 三、方案②：任意静态托管（把 base64 内容贴成 txt）

原理简单粗暴：把订阅内容（App「复制」出来的那段 base64，或明文节点都行）存成 `ct.txt`，丢到任何一个能 HTTP GET 到的地方，客户端订阅那个 URL。

### 3.1 可选 hosting

| 渠道 | 国内速度 | 费用 | 备注 |
|---|---|---|---|
| 腾讯云 COS / 阿里云 OSS + CDN | ⭐⭐⭐⭐⭐ | 几毛~几元/月 | 最稳，唯一要掏钱的 |
| Cloudflare Pages | ⭐⭐⭐ | 免费 | 拖文件就上传；`pages.dev` 同样建议绑自定义域 |
| GitHub Pages / Gitee Pages | ⭐⭐ | 免费 | 慢且偶发不通 |
| Vercel / Netlify | ⭐⭐ | 免费 | 国内不稳定 |
| paste.gg / catbox / 0x0.st | ⭐ | 免费 | 一条 curl 就能传，但寿命看运气，别放重要的 |

### 3.2 怎么更新

- 手动：App 里「复制」→ 存成 txt → 传到托管 → 完事。
- 半自动：如果托管商有写入 API（COS/OSS/CF Pages API/GitHub API 都有），本质就退化成方案① —— 只是把 Worker 换成别人的 API。**App 的「自定义上传 API」输入框就是为这种场景准备的**：POST 地址、口令、key 三个参数填对就能传。

### 3.3 隐私

静态链接 = 内容本身，谁拿到链接谁就能用。文件名别用 `ct.txt`，换成随机串（如 `f7a2c9e1.txt`），等于变相保密。

## 四、App 里怎么用（已内置）

接口管理 → 最下方「☁️云端订阅」→ 托管方式选：

- **GitHub**：填 Token、仓库（默认 cf-ip-data）、目录（默认 PrismTun）→ 上传得 raw 链接。
- **自定义 API**：填 Worker 地址（如 `https://sub.你的域名.com`）+ 上传口令 → 上传得 `.../ct` 链接，App 里直接复制，粘贴到客户端即可。

成功后链接会一直显示在卡里，随时复制；重新测完再点一次上传就是更新。

每一行都有四个按钮：

| 按钮 | 作用 |
|---|---|
| ☁️上传 | 把本机快照传到远端（同名 key 覆盖，链接不变） |
| 👁️远端 | **把云端存的内容拉回来弹窗显示**（base64 自动解码成明文节点），并告诉你云端多少条、本地多少条、两边是否一致 |
| 🔗直链 | 复制订阅地址（设了读口令的话已自动带好 token） |
| ⚡加速 | 仅 GitHub 模式有，复制 gh-proxy 加速地址 |

「👁️远端」就是用来核对"传上去的到底是什么"的：内容不对或条数对不上，重新点一次☁️上传即可同步。

## 五、安全提醒

- 口令只在写操作用，读订阅是公开的（客户端要能匿名拉，这是订阅的常态）。
- Worker 里已限制 key 只能是字母数字下划线、单文件最大 1MB，防止被拿来当网盘。
- 别把 `UPLOAD_TOKEN` 明文写进 `wrangler.toml` 提交到公开仓库。
